# Worktrees — контекст для агентов

macOS-приложение на Wails v2 для управления `git worktree` во всех репозиториях
выбранных папок-проектов. Что умеет и как запускать — в `README.md`.

## Устройство

| Файл                 | Что внутри                                                                 |
|----------------------|----------------------------------------------------------------------------|
| `main.go`            | настройка окна Wails, встраивание `frontend/dist`                          |
| `app.go`             | `App` — методы, доступные фронту; конфиг; список проектов (`roots`)        |
| `git.go`             | вся работа с git: поиск репо, разбор `worktree list`, статусы, rebase, pull |
| `menubar_darwin.go` + `.m` | иконка и меню в меню-баре (cgo + Cocoa), текущее окно VS Code       |
| `frontend/dist/`     | интерфейс: `index.html`, `style.css`, `app.js` — без сборки и зависимостей |
| `frontend/wailsjs/`  | генерируется `wails build` / `wails dev`, руками не править                 |
| `*_test.go`          | тесты на настоящих временных git-репозиториях                               |
| `.github/workflows/build.yml` | CI: gofmt, vet, тесты, универсальная сборка; на тег `v*` — релиз с zip |

- Фронт вызывает Go через `window.go.main.App.<Метод>()` (прокси `api` в `app.js`).
  Новый публичный метод `App` сразу доступен фронту после пересборки.
- Все вызовы git — через `git()` / `gitT()` / `gitRun()` в `git.go` с таймаутами
  `gitTimeout` и `networkTimeout` (fetch, pull). Не вызывать `exec.Command("git", …)` напрямую.
- Конфиг: `~/Library/Application Support/worktrees/config.json`. Ключи названий и
  закреплений — пути ворктри после `filepath.Clean`. Старое поле `root` (одна
  папка) при загрузке переносится в `roots` — эту миграцию не удалять.
- Состояние ворктри для интерфейса считает `triage()` в `app.js`: уровень
  (0 — в порядке, 1 — отстаёт/изменения, 2 — нужно разобраться), фраза и
  действие, которое решает проблему. Новые состояния добавлять туда.
- Приложение, запущенное из Finder, получает урезанный `PATH`; его дополняет
  `fixPath()` — помнить об этом при вызове внешних программ.

## Правила

- Интерфейс, тексты ошибок и комментарии — по-русски; идентификаторы — по-английски.
- Без привязки к конкретным проектам пользователя: никаких захардкоженных путей,
  имён репозиториев и доменов ни в коде, ни в документации, ни в тестах.
- Фронт остаётся без сборки: никаких npm-зависимостей и бандлеров.
- Тесты, которые трогают конфиг, подменяют `HOME` через `t.Setenv` — реальный
  конфиг пользователя тесты менять не должны.

## Проверка изменений

```sh
gofmt -l . && go vet ./... && go test ./...
make build    # убедиться, что приложение собирается
```

Интерфейс удобно проверять в браузере без Wails: подключить перед `app.js`
скрипт-заглушку, который определяет `window.go.main.App` с моковыми данными
(`GetRoots`, `ListRepos` и т. д.), и открыть `index.html`.
