# Worktrees

Десктоп-приложение для macOS, которое собирает в одном окне все `git worktree`
из репозиториев ваших проектов и даёт быстро открыть нужный в VS Code,
подтянуть изменения или сделать rebase на основную ветку.

Сделано на [Wails v2](https://wails.io): бэкенд на Go вызывает системный `git`,
интерфейс — обычные HTML/CSS/JS без сборки.

## Что умеет

**Проекты.** Проект — это папка, в которой лежат git-репозитории. Проектов может быть
сколько угодно: «＋ Добавить проект» внизу сайдбара. Репозитории ищутся до трёх
уровней вглубь (скрытые папки и `node_modules` пропускаются). Проект можно убрать из
списка — на диске ничего не удаляется.

**Список ворктри.** Для каждого ворктри видно:

- состояние одной фразой и цветной точкой: всё в порядке, отстаёт / есть изменения,
  нужно разобраться (остановленный rebase, будущие конфликты, удалённая на remote
  ветка, пропавшая папка);
- шкалу расхождения с основной веткой: влево — сколько новых коммитов в основной
  ветке, вправо — сколько своих коммитов у ветки; штриховка — rebase даст конфликты
  (проверяется пробным `git merge-tree` в памяти, рабочая копия не трогается);
- незакоммиченные изменения, ↓/↑ относительно upstream, lock, время последнего
  изменения (коммит или mtime изменённых файлов).

Группы в сайдбаре: все ворктри, закреплённые, требующие внимания, по проекту и по репо.
Сортировка: порядок git, недавно изменённые, давно не менявшиеся.

**Действия.**

- открыть в VS Code (двойной клик или ↵; всегда в текущем окне, `code -r`), Finder, Terminal;
- Pull (fast-forward, при расхождении — `--rebase`), «Pull все» по репо;
- Rebase на основную ветку с `--autostash`; если ожидаются конфликты — rebase
  останавливается, ворктри открывается в VS Code, дальше «Продолжить» или «Отменить»;
- Fetch по репо и во всех; фоновый fetch при запуске и каждые 10 минут;
- создать ворктри с новой веткой (от выбранной базы) или из существующей
  локальной / удалённой ветки (с `--track`); путь по умолчанию —
  `<проект>/.worktrees/<репо>/<ветка>`;
- своё название ворктри (привязано к папке, переживает смену веток), закрепление;
- удалить один или несколько ворктри (`--force` при изменениях или lock) и, по желанию, ветки;
- `git worktree prune` для ворктри, чьи папки уже удалены.

**Меню-бар.** Иконка в меню-баре показывает ворктри, открытый в активном окне
VS Code (берётся из `storage.json` VS Code, без запроса прав), а в меню — все
ворктри для быстрого переключения. Закрытие окна не завершает приложение.

**Клавиши.**

| Клавиши        | Действие                                  |
|----------------|-------------------------------------------|
| ↑ / ↓          | выбрать ворктри                           |
| ↵              | открыть в VS Code                         |
| ⌘-клик, Shift-клик | выбрать несколько                     |
| ⌘⌫             | удалить выбранные                         |
| Esc            | снять выделение                           |
| ⌘N             | новый ворктри в текущем репо              |
| ⌘F             | поиск                                     |
| ⌘R             | обновить                                  |

## Требования

- macOS (меню-бар написан на Cocoa через cgo);
- Go 1.27+ и Xcode Command Line Tools (`xcode-select --install`);
- git 2.38+ (нужен `git merge-tree --write-tree` для проверки конфликтов);
- VS Code с командой `code` в `PATH` — желательно; без неё папка открывается через `open -a`.

## Запуск

```sh
go install github.com/wailsapp/wails/v2/cmd/wails@latest   # один раз

make dev       # режим разработки: правки во frontend/dist подхватываются сразу
make build     # собрать build/bin/Worktrees.app
make install   # собрать и скопировать в /Applications
make test      # go test ./...
```

Фронт лежит в `frontend/dist` как есть — npm и сборка не нужны.

## Где хранятся настройки

`~/Library/Application Support/worktrees/config.json`: список папок проектов,
свои названия ворктри и закрепления. Файл можно править руками, пока приложение
закрыто.
